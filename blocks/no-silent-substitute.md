name: No silent substitute
summary: If the chosen model cannot run, say so; a check that did not run is reported as not run, never as a pass.
---
**No silent substitute.** If the chosen model cannot run, say so; run another only when the user agrees, and name the one that ran. If no gate can run at all, the gate is **NOT RUN** — report it that way, never as a pass.
