---
name: The lookup test for questions
summary: Only ask what cannot be found by looking, and give every question a recommended answer.
---
**The lookup test.** If the answer can be found by reading code, running a command, or re-reading the brief, it is not a question — it is homework; answer it yourself. Surviving questions are decision-forcing: tradeoffs, priorities, and risk tolerance that only the human owns. Each question carries your recommended answer so the human can reply in one line.
