---
name: Report format
summary: Lead with the answer, back every claim about code with evidence or label it unverified, and report once.
---
**Answer first.** Lead with the conclusion, the decision the operator has to make, or the thing that broke. Detail comes after, and only if it changes what they do next.

**Claims about code need evidence.** Any statement about how code behaves needs a command you ran, a file you read, or a test that passed in this session. Without that, label it: `unverified —`.

**Report once.** One report, after the fix round and the fix check: what was fixed, what was deferred and what was filed, each with its numbers.
