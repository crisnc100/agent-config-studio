# Native Antigravity builder

Explicit `ask-model --build` uses the shared runner and Antigravity's native `accept-edits` mode at the supplied Git top. The wrapper pins the tested CLI version, checks for plaintext token storage, and removes its private per-call log. Successful builds report native completion and unverified model identity. Failed or cancelled builds can leave edits in the worktree.

The isolated prototype modules are archived byte-for-byte. `AGY_SETTINGS`, `AGY_WALL` and the review runtime match the phase baseline byte-for-byte.

Sequential macOS checks used `ACS_LIVE_CHECKS=0` and `taskpolicy -b`. The installed fake-CLI build passed 11 tests. The archived source, lifecycle and wall suites passed 10, 10 and 4 tests. The unchanged read-only Antigravity CLI and wall suites passed 88 assertions each, with the read-only CLI's usual off-macOS branch skipped on macOS. The ACS update suite passed 23 assertions.
